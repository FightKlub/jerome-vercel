# Jerome Richard D - Portfolio Website 🚀

A modern, interactive portfolio website showcasing my skills as a Full Stack Developer, AI Engineer, Data Engineer, and Cloud Architect.

## 🌐 Live Demo

[View Live Site](https://jerome-vercel.vercel.app)

## ✨ Features

- **3D Interactive Character** - Animated 3D model using Three.js
- **Smooth Animations** - GSAP-powered scroll animations
- **Responsive Design** - Works on all devices
- **Modern UI/UX** - Clean, professional design

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript
- **3D Graphics**: Three.js, React Three Fiber, Drei
- **Animations**: GSAP, ScrollTrigger
- **Styling**: CSS3
- **Build Tool**: Vite
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/FightKlub/jerome-vercel.git

# Navigate to the project
cd jerome-vercel

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📁 Project Structure

```
src/
├── components/     # React components
├── config.ts       # Site configuration (name, skills, projects)
├── context/        # React context providers
├── data/           # Static data
└── utils/          # Utility functions
```

## 📝 Customization

Edit `src/config.ts` to update:
- Personal information
- Skills and technologies
- Work experience
- Projects
